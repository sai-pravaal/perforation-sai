Phase 17 Completion Summary: Frontend Category G - Validation & Patent-Support

Phase 17 adds frontend/tabs/validation_tab.py and completes the planned extensions to the frontend validation and patent-support surface. ValidationTab routes labelled-specimen validation runs and report retrieval through frontend.client.Client. ResultsTab now exposes config snapshots and quality-gate results in addition to its Phase 15 reporting actions. UploadTab exposes a quality-gate action for the current capture session.

MainWindow now provides the application tab container for Upload, Processing, View, Results, and Validation, sharing one Client instance across the UI. Backend computation, validation, report generation, quality gating, and file access remain in backend/api.py and its services.

No direct frontend file I/O, scientific-library imports, synthetic images, or specimen datasets were added. A focused import and method-presence test is provided in tests/test_phase17_frontend.py. Phase 18 testing remains pending.

Update (2026-10-25 audit): ValidationTab runs validation in the background and renders a TP/FP/FN/TN card, a Matplotlib ROC-style plot, a per-specimen table with region overlap, and a repeatability table. run_quality_gate is now the real Feature 29 pre-run gate (backlit bimodality, torch exposure consistency, calibration detection) used by the Upload tab. The validation engine checks each run result, keeps specimen sessions inside the run folder, copies specimen session logs, and adds overlap_with_ground_truth. A list of available specimen sets is not shown because the API has no function to list them. Open items that still block full compliance (decision needed or needs real capture data): API-01 no upload/start entry point in the frozen 29-function API (files must be placed in raw/ and the run is started through reprocess_from_stage step 1); API-03 no PDF report entry point in the API (Export PDF button disabled); STAT-01 summed-z cutoff 3.0 versus the L2 norm of 14 z-scores; STAT-02 shadow_direction_deg z-scored linearly although circular; PIPE-05 interior holes forced onto an edge; PIPE-06 tooth chord points in the circle fit; PIPE-07 backlit exterior and tooth detection; PDF-01 table width; SESS-06 client.py error convention differs between the plan and the frontend spec.
